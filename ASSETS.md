# Assets not in this repo

This repository holds **source only**. 2.2 MB of payload — model weights, volumes, imagery, meshes, fonts — is left out, because it is either re-fetchable, regenerated, or licensed in a way that makes redistribution a bad idea.

## Getting it back

Everything below is either restored by Unity itself (package samples, TextMesh Pro essentials) or re-imported from its original source. Nothing here is authored in this project.

### TextMesh Pro

`Window → TextMeshPro → Import TMP Essential Resources` restores the font atlas and shaders if any are listed below.

### Package samples

Anything under `Samples/` comes from a package: Package Manager → the package → Samples → Import.
